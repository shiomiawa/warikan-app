# 割り勘アプリ Claude Code指示書（6章の手順準拠）

## プロジェクト名

**`warikan-app`**

- フォルダ名・GitHubリポジトリ名ともにこの名前で統一します（英小文字・ハイフン区切り）
- 公開URLは `https://ユーザー名.github.io/warikan-app/` になります
- 別案：`split-trip`（旅行寄り）、`warikan-calc`（計算寄り）

---

## STEP 1. プロジェクトフォルダの作成

1. VS Codeで「ファイル > フォルダーを開く」→ `Documents` 内に `warikan-app` フォルダを作成して開く
2. フォルダ内に `docs` フォルダを作り、以前作成した設計書を2つコピーしておく
   - `docs/warikan_design.md`（詳細版）
   - `docs/warikan_design_overview.md`（全体図）
3. Claude Codeを起動し「＋ New Session」で新しいセッションを開始

---

## STEP 2. CLAUDE.mdの作成

```
このプロジェクト用のCLAUDE.mdを作成してください。
Git運用ルールとして、コードを変更するたびに
GitHubにプッシュする旨も含めてください。

【プロジェクト概要】
複数人で簡単に割り勘ができるReactアプリです。
飲み会・旅行での立て替えを記録し、最終的に「相殺後」の送金額を表示します。

【設計書】
docs/warikan_design.md と docs/warikan_design_overview.md に
画面遷移・データ構造・計算フローがあります。実装はこの設計に従ってください。

【ルール】
- 金額は整数（円）で扱う
- 画面の文言はすべて日本語
- スマートフォンでも使いやすいレイアウトにする
```

---

## STEP 3. GitHubリポジトリの作成と初回プッシュ

GitHubで `warikan-app` リポジトリを **Public** で作成し、URLをコピーしてから指示します。

```
このプロジェクトをGitで初期化して、以下のGitHubリポジトリにプッシュしてください。
リポジトリURL：https://github.com/ユーザー名/warikan-app.git
```

> URLは自分のリポジトリのものに差し替えてください。

---

## STEP 4. 基本機能の作成（割り勘と相殺）

タスクボードと違い機能が多いため、一度に全部作らず段階的に指示します。

```
Reactで割り勘アプリを作成してください。
docs/warikan_design.md の設計に従ってください。

【機能】
- イベント（例：箱根旅行）を作成できる
- メンバーをニックネームで登録できる
- 支払い項目を追加できる（項目名・金額・立て替え者）
- 負担の割り方を項目ごとに選べる
  - 均等割り
  - 比率指定（例：アルコール多め7・少なめ3・対象外0）
  - 金額指定
- 端数処理（1円・10円・100円単位）を選べ、余りは立て替え者に寄せる
- 精算結果画面で以下を表示する
  - 明細：項目ごとの各人の負担額
  - 相殺後：誰が誰にいくら払うか（送金回数が最少になるように）
```

完成したら：

```
開発サーバーを起動して、ブラウザで確認できる状態にしてください。
```

**動作確認の例**：A・B・Cの3人で、Aがホテル30,000円、Bが夕食9,000円を立て替え、飲み物3,000円をA多め7・B少なめ3・C対象外で割る → 相殺後の金額が手計算と合うか確認

---

## STEP 5. ガソリン代の計算を追加

```
支払い項目に「ガソリン代」の種類を追加してください。

【機能】
- 走行距離の入力方法を選べる
  - オドメーターの出発時・到着時の数値から計算
  - 距離（km）を直接入力
- 燃費（km/L）とガソリン単価（円/L）を入力する
- 金額 = 距離 ÷ 燃費 × 単価 で自動計算する
- 計算した金額は通常の項目と同じく、立て替え者と負担の割り方を設定できる
```

---

## STEP 6. ETC料金の記録を追加

```
支払い項目に「ETC」の種類を追加してください。

【機能】
- 入口IC・出口IC・通過日時・車種区分・適用割引（深夜・休日など）を入力できる
- 金額は「概算額」と「確定額」の2つを持てる
- 状態を「未入力・概算・確定」で管理し、一覧で状態がわかるように表示する
- 精算の計算では、確定額があれば確定額、なければ概算額を使う
- 概算額を調べるため、NEXCOの料金検索（ドラぷら）を開くリンクを表示する
```

---

## STEP 7. ローカルストレージで保存

```
イベント・メンバー・支払い項目をローカルストレージに保存して、
ページをリロードしても消えないようにしてください。
```

確認：項目を追加 → リロード → データが残っているか

---

## STEP 8. GitHub Pagesで公開

```
このアプリをGitHub Pagesで公開できるよう準備してください。
```

その後、GitHubのリポジトリページ →「Settings」→「Pages」で、Claude Codeの返答に従って「Source」を設定します。数分後に `https://ユーザー名.github.io/warikan-app/` で確認できます。

## 補足

- STEPごとに動作確認してから次へ進むと、不具合の原因が特定しやすくなります
- ローカルストレージのデータは各自のブラウザにしか保存されません。仲間と共有する機能は、8章のSupabase（データベース）を学んだ後に追加するのがおすすめです
- Googleマップ等での距離自動取得も、基本機能が完成してから追加します
